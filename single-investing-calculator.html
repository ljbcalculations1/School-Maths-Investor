How does the calculation work?

A simple compound-interest calculation often assumes an investment earns the same return every year. Real markets do not behave like that: returns vary from month to month.

This calculator starts with one lump sum and applies the actual historical monthly real return for each month in the selected ten-year period.

New Portfolio Value

= Previous Portfolio Value × (1 + Monthly Real Return)
Simple example

Suppose you invest £10,000 and the market rises by 5% in real terms.

£10,000 × 1.05 = £10,500

If the next month's real return is −2%:

£10,500 × 0.98 = £10,290

The calculator repeats this process using the historical real return for every month.

What does “Annualised Real Return” mean?

Because the whole lump sum is invested at the start, all the money is exposed to every monthly return in the selected period.

The annualised real return is the constant annual rate that would turn the initial investment into the final value over ten years, after accounting for inflation.

Annualised Real Return = (Final Value ÷ Initial Investment)1/10 − 1

This is a compound annual growth rate (CAGR). It summarises the overall outcome; it does not mean the investment actually grew at that rate each year.

Why use real returns?

Investment returns are often quoted in nominal terms, but inflation reduces what money can buy.

This calculator adjusts historical global equity returns for UK inflation. Results are therefore expressed in real terms — approximately today's purchasing power.

A final value of £15,000 represents roughly £15,000 of purchasing power in today's money, not £15,000 of cash at the historical end date.

How are the real returns calculated?

Nominal investment return is calculated from the change in the MSCI ACWI Total Return Index:

Nominal Return = (Current Index ÷ Previous Index) − 1

Monthly inflation is calculated from the change in the UK CPIH index:

Inflation = (Current CPIH ÷ Previous CPIH) − 1

The nominal return is adjusted for inflation:

Real Return = (1 + Nominal Return) ÷ (1 + Inflation) − 1

The resulting monthly real return is applied to the lump sum.

Why start in February 1988?

A monthly return requires the previous month's index value. The first usable real return in this dataset is therefore February 1988.

These historical data demonstrate how a lump sum would have behaved through different market conditions; they are not a prediction of future returns.

Past performance does not guarantee future results.

What can this calculator teach us?

  • Investment returns can themselves generate further returns through compounding.
  • The starting date matters because the sequence of returns differs across periods.
  • Investment returns are variable rather than constant.
  • Inflation affects purchasing power.
  • A long investment period gives compounding time to work, but does not remove the risk of loss.
  • A lump sum is exposed to the market from the beginning, unlike money invested gradually over time.

The aim is not simply to produce a number. It is to use mathematics to understand what that number means.
