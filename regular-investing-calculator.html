How does the calculation work?

A normal compound-interest calculation often assumes that the investment earns the same return every year.

Real investments don't behave like that.

The stock market can rise strongly in one month and fall sharply the next. This calculator therefore applies the actual historical monthly return for each month in the investment journey.

New Portfolio Value

= (Previous Portfolio Value + Monthly Investment) × (1 + Monthly Return)

This calculation is repeated every month for ten years.

Simple example

Suppose you start with £200 and the market rises by 5%.

£200 × 1.05 = £210

If you then add another £200 and the next month's return is -2%:

(£210 + £200) × 0.98 = £401.80

The calculator repeats this process using the actual historical return for every month.

What does the annualised return mean?

Because you are investing money every month rather than investing the whole amount at the beginning, the final portfolio value cannot be converted into an annual return using a simple compound-interest formula.

The calculator therefore calculates the annualised return using the actual timing of each monthly investment.

Annualised Return

The annual return that would produce the same final portfolio value from the same sequence of monthly investments.

In other words, it answers the question:

"What constant annual return would have produced the same result from these monthly investments?"

This is different from simply taking the average of the monthly returns. It also takes account of the fact that each contribution was invested for a different length of time.

Why use real returns?

Investment returns are often quoted in nominal terms. But inflation reduces what your money can actually buy.

This calculator therefore adjusts the historical investment returns for UK inflation.

The results are therefore expressed in real terms — approximately today's purchasing power.

This makes the results easier to interpret when thinking about long-term financial goals.

How are the real returns calculated?

For each month, the nominal investment return is calculated from the change in the MSCI ACWI Total Return Index.

Nominal Return = (Current Index ÷ Previous Index) − 1

Monthly inflation is calculated from the change in the UK CPIH index.

Inflation = (Current CPIH ÷ Previous CPIH) − 1

The nominal return is then adjusted for inflation:

Real Return = (1 + Nominal Return) ÷ (1 + Inflation) − 1

The resulting monthly real return is then applied to the investment portfolio.

Why start in February 1988?

A monthly return requires the previous month's index value. The first usable real return in this dataset is therefore February 1988.

The historical data are used to demonstrate how regular investing has behaved through different market conditions. They are not a prediction of future investment returns.

Past performance does not guarantee future results.

What can this calculator teach us?

Regular investing demonstrates several important ideas from mathematics and investing.

  • Compound growth means that investment returns can themselves generate further returns.
  • The timing of contributions matters.
  • Investment returns are variable rather than constant.
  • Inflation affects the purchasing power of investment returns.
  • A long investment period gives compounding more time to work.
  • The annualised return depends on both investment performance and the timing of contributions.

The aim is not simply to produce a number. It is to use mathematics to understand what that number means.
